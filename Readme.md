# Portfolio Optimization & Efficient Frontier Engine

A quantitative finance Python project that fetches historical stock data, performs Modern Portfolio Theory (MPT) optimization, and computes/visualizes the **Efficient Frontier** and **Monte Carlo Portfolio Simulations**.

---

## 📈 Overview

This project provides an end-to-end workflow for quantitative portfolio management focused on Indian equity markets (NSE). By analyzing historical adjusted closing prices over a 10-year period, the model calculates optimal asset allocation weights to maximize the **Sharpe Ratio** under predefined constraints.

It combines custom mathematical optimization algorithms (`scipy.optimize`) with modern portfolio optimization frameworks (`PyPortfolioOpt`) and visualizes the results with Matplotlib.

---

## 🚀 Key Features

- **Automated Data Ingestion:** Fetches 10 years of historical stock prices via the `yfinance` API for specified stock tickers.
- **Lognormal Returns & Risk Metrics:** Calculates lognormal returns, annualised covariance matrices, expected returns, and portfolio volatility.
- **Sharpe Ratio Optimization:** 
  - Solves for maximum Sharpe Ratio allocations using Sequential Least Squares Programming (`SLSQP`) from `scipy.optimize`.
  - Implements realistic allocation bounds (e.g., maximum 50% allocation per individual asset).
- **Efficient Frontier Analysis:** Utilizes `PyPortfolioOpt` to compute the tangency portfolio and theoretical efficient frontier curve.
- **Data Visualization:** Generates publication-ready Efficient Frontier plots using Matplotlib with `fivethirtyeight` styling.

## ⚙️ How It Works

### 1. Define Tickers and Download Data
The notebook initializes a basket of NSE tickers and pulls the last 10 years of adjusted closing prices:
```python
tickers = ['ICICIBANK.NS', 'RELIANCE.NS', 'BHARTIARTL.NS', 'NTPC.NS']
```

### 2. Log Returns & Covariance Matrix
Calculates annualised daily lognormal returns and the covariance matrix scaled for standard 252 trading days:
$$\text{Log Returns} = \ln\left(\frac{P_t}{P_{t-1}}\right)$$
$$\text{Covariance Matrix} = \text{Cov}(\text{Log Returns}) \times 252$$

### 3. SLSQP Optimization
Using scipy's `minimize` with equality constraints ($\sum w_i = 1$) and bounds ($0 \le w_i \le 0.5$):

$$\text{Sharpe Ratio} = \frac{E(R_p) - R_f}{\sigma_p}$$

Assuming a Risk-Free Rate ($R_f$) of **6.0% p.a.**:

```python
# Optimal allocations generated by the model
Optimal Weights:
- BHARTIARTL.NS: 41.18%
- ICICIBANK.NS:  26.29%
- RELIANCE.NS:   23.21%
- NTPC.NS:        9.32%
```
